About the Project

What is Study Buddy?

Study Buddy is a simple productivity tool designed for students to organize study tasks, maintain focus and build consistent study habits.

Built using standard Web Development standards (HTML5, Tailwind CSS, and pure Vanilla JavaScript) without dependencies on external heavy JS frameworks. It proves how modern web experiences can be fast, lightweight, and completely privacy-respecting by storing data locally in the browser.

HTML5 Semantic Structure Tailwind CSS Utility Design Vanilla JS DOM Manipulation HTML5 LocalStorage API
